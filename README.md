# ultratech
Loja online para jogos modernos

home.html é a tela inicial, aonde tem o catálogo que te direciona para as páginas dos produtos

cadastrar.html e login.html são as telas de login e cadastro básicas do projeto

blog.html é a página de blog do site aonde tem as notícias mais recentes do mundo dos jogos

os produtos tem sua página prórpia cada um e ficam guardados na pasta produtos dentro da pasta de htmls
